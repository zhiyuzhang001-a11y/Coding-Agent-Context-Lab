# v0.1.0 — Research Complete

This release freezes the public research archive of Coding Agent Context Lab / Agent Token Manager.

## Status

`RESEARCH_COMPLETE / PRODUCT_NOT_VALIDATED / MAINTENANCE_ONLY`

The project did not validate a transparent, general-purpose token-saving product for the current coding-agent Host. It did establish reproducible measurement boundaries, negative results, local evidence-reduction results, and a budgeted code-navigation prototype.

## Included

- Frozen conclusions and methodology for the intervention and attribution studies.
- Public-safe fixtures, registries, checksums, and offline verification tests.
- An installable Codex marketplace containing the `agent-token-manager` research plugin.
- Observe-only audit tooling and budgeted code-reading/navigation utilities.
- Clear separation between measured usage, estimated attribution, and causal savings claims.
