## 目录职责

- `conclusions/`：结项报告和决定项目边界的冻结结果。
- `methodology/`：验证范围、合同、长期约束和 baseline 定义。
- `results/`：各阶段结果、pilot、readiness 和审计记录。
- `history/`：实施计划与历史状态，用于追踪研究过程，不代表当前 roadmap。
